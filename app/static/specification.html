Pipeline Specification & Grounding Contract

Formal specifications, RFC 8259 schema contracts, validation heuristics, and runtime operational constraints governing transcript ingestion, deterministic grounding, and multi-model LLM inference.

PIPELINE SPECIFICATION DETERMINISTIC GROUNDING
01
Ingest & Boundary Alignment
FFmpeg 16 kHz mono normalization; Groq Whisper large-v3 word timestamps or .srt/.vtt cue indexing into segments S0..Sn. Timestamps originate strictly from ASR or cue markers, never from LLM synthesis.
02
Multi-Provider Inference Chain
Gemini 1.5 Flash / Groq (Llama 3.3 70B / gpt-oss-120b) execution with automatic rate-limit cooldown, JSON schema repair, and provider fallback across Google AI Studio, Groq Cloud, and HuggingFace.
03
Deterministic Grounding Engine
Strict n-gram substring verification. Uncited claims and unsupported quiz evidence are automatically purged. If quote verification fails, the model is re-prompted with specific missing quotes before trying fallback providers.

Deterministic Grounding & Verification Rules

Language models propose structured outputs; deterministic Python code verifies evidence before rendering to the listener.

Component Verification Heuristic Failure Action
Timestamps Read directly from Whisper word-level timestamps or WebVTT / SRT cue markers. Never requested from the LLM. Absent timestamps explicitly flagged in UI; passage bounds displayed instead.
Quiz Evidence Verbatim quote must match transcript text near cited segment (Unicode-aware, case/punctuation-insensitive). Discard ungrounded question. If < 3 survive, re-ask model with exact quote mismatch details.
Takeaway Citations Citations must map to valid integer segment IDs present in the ingestion index. Uncited takeaways are purged prior to presentation.
Source Q&A Answers must include verbatim quote found in source transcript. Downgraded to honest refusal: "The provided transcript does not contain information about this."
